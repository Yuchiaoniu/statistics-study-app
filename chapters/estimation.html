估計理論 · 點估計與區間估計

推論統計的第一個問題：「我只有樣本，怎麼猜母體的參數？」估計理論回答「猜什麼」和「猜得好不好」。

觀念 1：點估計 vs 區間估計

方式給出的答案例子優缺點
點估計 一個數字 「母體均值估計是 70 kg」 簡單直觀，但沒說明誤差有多大
區間估計 一個範圍 「母體均值在 68～72 kg 之間（95% 信心）」 含不確定性資訊，但範圍寬度受 n 影響

點估計告訴你「最佳猜測是什麼」，區間估計告訴你「這個猜測有多可靠」。兩者互補，不是替代關係。

常用點估計量

母體參數符號樣本估計量
母體均值μ樣本均值 x̄
母體變異數σ²樣本變異數 s²（分母 n−1）
母體比例p樣本比例 p̂ = x/n

觀念 2：估計量的三大性質

同一個母體參數可以有很多種估計量，哪種比較「好」？統計學用三個標準評分。

性質一：不偏性（Unbiasedness）

估計量的期望值等於母體真值——平均來說不會高估也不會低估。

定義： 
E(θ̂) = θ
θ̂（theta hat）是估計量，θ 是母體真值

範例：x̄ 是 μ 的不偏估計量，因為 E(x̄) = μ。

反例：用 n 當分母算的「有偏變異數」，E 值會比 σ² 小，所以改用 n−1 修正。

反常識點：不偏估計量每次猜的不一定準，只是「多次抽樣的平均」剛好等於真值。單次猜測可能偏很多，不偏性是長期平均的保證，不是單次的保證。

性質二：一致性（Consistency）

樣本量 n 越大，估計量越接近母體真值——n → ∞ 時估計量收斂到 θ。

n 越大 → 估計誤差越小 → 估計量越可靠

x̄ 同時具備不偏性與一致性，這是它被廣泛使用的原因。

性質三：有效性（Efficiency）

在所有不偏估計量中，變異數最小的那個最有效——猜測結果最集中、波動最小。

性質白話意義數學定義
不偏性平均來說不偏左也不偏右E(θ̂) = θ
一致性樣本越多越準n↑ → θ̂ → θ
有效性猜測結果最集中Var(θ̂) 最小

觀念 3：最大概似估計（MLE）

MLE 是點估計的另一種方法：「哪個參數值，最能讓我觀察到手上這筆資料？」

核心邏輯

觀察到資料 x₁, x₂, ..., xₙ
假設來自某個分配，參數是 θ（未知）

概似函數 L(θ) = P(觀察到這筆資料 | 參數是 θ)

MLE 的答案：選讓 L(θ) 最大的那個 θ̂

白話類比：射箭後看箭落在哪裡，反推「射手的準心最可能在哪個位置」——從結果反推最合理的原因。

對數概似函數

直接對 L(θ) 求最大值計算複雜（連乘），實務上改對 ln L(θ)（對數概似函數）求最大值，結果相同但計算簡單。

ln L(θ) = Σ ln f(xᵢ | θ)

對 θ 微分後令等於 0，解出 θ̂_MLE

MLE 的重要性質

性質說明
一致性n → ∞ 時，θ̂_MLE → θ（真值）
漸近常態性n 夠大時，θ̂_MLE 近似常態分配，可用來建立信賴區間
漸近有效性大樣本下，MLE 在所有一致估計量中變異數最小

MLE vs x̄：對常態母體估計 μ，MLE 算出來的答案就是 x̄。但 MLE 的優勢在於可以推廣到任何分配（不限常態），是統計學最通用的估計方法。

觀念 4：信賴區間寬度與樣本量

信賴區間的公式：

         s
x̄ ± Z · ──
        √n
誤差範圍（Margin of Error）= Z · s/√n

影響區間寬度的三個因素

因素變大時區間寬度原因
n（樣本量）↑ 增加↓ 變窄√n 變大，SE 縮小，估計更精準
s（樣本標準差）↑ 增加↑ 變寬資料本身更分散，估計更不確定
信賴水準（1−α）↑ 增加（如 95%→99%）↑ 變寬Z 值變大（1.96→2.575），要框住更大範圍

反常識點：信賴水準越高，區間反而越寬——99% 信賴區間比 95% 更寬。要「更有把握」的代價是「說得更模糊」。精準和信心是互相拉扯的。

要讓誤差範圍縮小一半，n 需要變成 4 倍

誤差範圍 = Z · s/√n

n → 4n 時：Z · s/√(4n) = Z · s/(2√n) = 原本的一半

這解釋了為什麼大型調查（如選舉民調）需要上千個樣本：多收 100 份問卷，精準度的改善其實很有限。
