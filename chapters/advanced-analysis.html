第 11-15 章 · 進階分析

建立在假設檢定基礎上的三大進階工具：ANOVA 同時比較多組平均、線性迴歸建立預測模型、卡方檢定分析類別資料。

ANOVA（F 檢定）

想比較三組學生的平均成績，跑三次 t 檢定會累積型 I 誤差。ANOVA 一次搞定：把「總變異」拆成組間與組內，用 F 值判斷組間差異是否大到不像雜訊。

核心邏輯：拆解總變異

ANOVA 的核心想法：如果組間差異大，相對組內的隨機波動，F 值就會偏大，超過臨界值就拒絕 H₀。

$$F = \frac{MS_{between}}{MS_{within}} = \frac{SSB/df_B}{SSW/df_W}$$
符號解釋
$SSB$
Sum of Squares Between groups，組間平方和——量每組平均與總平均的距離
$SSW$
Sum of Squares Within groups，組內平方和——量每個觀測值與該組平均的距離
$df_B = k - 1$
組間自由度，$k$ 為組數
$df_W = N - k$
組內自由度，$N$ 為總觀測數，$k$ 為組數
$MSB = SSB/df_B$
組間均方（Mean Square Between）——組間「每個自由度的變異」
$MSW = SSW/df_W$
組內均方（Mean Square Within）——相當於共同誤差的估計
$F$
F 統計量，服從 $F(df_B,\, df_W)$ 分配；$F$ 越大代表組間差異相對組內雜訊越顯著

完整計算範例

三組各 3 筆觀測，比較三組平均是否相同：

群組觀測值組平均 $\bar{x}_j$
Group A2, 4, 64
Group B4, 6, 86
Group C6, 8, 108

總平均 $\bar{x} = (4 + 6 + 8)/3 = 6$，$k = 3$，$N = 9$。

Step 1：計算 SSB（組間平方和）

$$SSB = n_j \sum_{j=1}^{k}(\bar{x}_j - \bar{x})^2 = 3\times[(4-6)^2 + (6-6)^2 + (8-6)^2]$$
$$= 3 \times [4 + 0 + 4] = 3 \times 8 = 24, \quad df_B = k - 1 = 2, \quad MSB = 24/2 = 12$$

Step 2：計算 SSW（組內平方和）

$$SSW = \sum_{j}\sum_{i}(x_{ij} - \bar{x}_j)^2$$
$$= [(2-4)^2+(4-4)^2+(6-4)^2] + [(4-6)^2+(6-6)^2+(8-6)^2] + [(6-8)^2+(8-8)^2+(10-8)^2]$$
$$= [4+0+4] + [4+0+4] + [4+0+4] = 8 + 8 + 8 = 24, \quad df_W = N - k = 9 - 3 = 6, \quad MSW = 24/6 = 4$$

Step 3：計算 F 值

$$F = \frac{MSB}{MSW} = \frac{12}{4} = 3.0$$

查 F 表：$F_{0.05}(2, 6) \approx 5.14$。因為 $3.0 < 5.14$，未達顯著水準，無法拒絕 H₀（三組平均數沒有顯著差異的證據）。

選擇題 · ANOVA

簡單線性迴歸

找一條最佳直線來描述兩個變數的關係——X 每增加 1 單位，Y 平均增加多少？目標是讓「殘差平方和」最小（最小平方法 OLS）。

迴歸方程式

$$\hat{y} = b_0 + b_1 x$$
符號解釋
$\hat{y}$
讀作「y hat」，模型預測的 y 值（不是真實觀測值）
$b_0$
截距（intercept）：當 $x = 0$ 時，$\hat{y}$ 的值
$b_1$
斜率（slope）：$x$ 每增加 1 單位，$\hat{y}$ 平均增加 $b_1$ 單位
$x$
自變數（predictor / independent variable），已知的輸入值
$R^2$
判定係數，代表迴歸模型解釋了多少比例的 y 變異（$0 \le R^2 \le 1$）

OLS 估計公式

$$b_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}$$
$$b_0 = \bar{y} - b_1 \bar{x}$$

完整計算範例

資料：$(1, 2),\ (2, 4),\ (3, 6)$——完美線性關係。

$\bar{x} = 2,\quad \bar{y} = 4$

$$b_1 = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2} = \frac{4}{2} = 2$$
$$b_0 = \bar{y} - b_1\bar{x} = 4 - 2 \times 2 = 0$$
$$\hat{y} = 2x$$

$R^2 = 1.0$——模型完全解釋 y 的所有變異（完美線性關係）。

$R^2$ 的解讀
  • $R^2 = 0.80$：模型解釋了 80% 的 y 變異，剩下 20% 是其他因素或隨機誤差
  • $R^2 = 0$：迴歸線完全無用（斜率 = 0）
  • $R^2 = 1$：完美預測（如本例）——現實中幾乎不存在

卡方檢定

觀察到的次數分配，與理論期望的次數分配，差距有多大？$\chi^2$ 量化這個差距，用於驗證分配是否吻合，或兩個類別變數是否獨立。

卡方統計量公式

$$\chi^2 = \sum \frac{(O - E)^2}{E}$$
符號解釋
$O$
Observed frequency，實際觀察到的次數
$E$
Expected frequency，在 H₀ 成立下的期望次數
$(O-E)^2$
差距平方（消除正負方向）
$(O-E)^2/E$
相對差距：同樣差 3 次，期望 10 vs 期望 100，嚴重程度完全不同
$\sum$
對所有類別加總

兩種用途

用途問題$df$
適合度檢定
Goodness of Fit		 資料是否符合某理論分配？（例：骰子是否公平？） 類別數 $k - 1$
獨立性檢定
Test of Independence		 兩個類別變數是否獨立？（例：性別與偏好是否相關？） $(r-1)(c-1)$，$r$ 列 $c$ 欄

完整計算範例（適合度檢定）

丟一顆骰子 60 次，各面觀察次數如下。H₀：骰子公平（每面出現機率 1/6）。

骰子面123456合計
觀察次數 $O$810911121060
期望次數 $E$10101010101060
$(O-E)^2/E$4/1001/101/104/100—
$$\chi^2 = \frac{(8-10)^2}{10} + \frac{(10-10)^2}{10} + \frac{(9-10)^2}{10} + \frac{(11-10)^2}{10} + \frac{(12-10)^2}{10} + \frac{(10-10)^2}{10}$$
$$= \frac{4}{10} + 0 + \frac{1}{10} + \frac{1}{10} + \frac{4}{10} + 0 = \frac{10}{10} = 1.0$$

$df = k - 1 = 6 - 1 = 5$，臨界值 $\chi^2_{0.05, 5} = 11.07$。

因為 $1.0 < 11.07$，不拒絕 H₀——沒有顯著證據說明骰子不公平。

關鍵注意事項
  • 期望次數 ≥ 5：每格 $E$ 最好不低於 5，否則卡方近似不可靠
  • 單向檢定：卡方統計量永遠非負，只看右尾（拒絕域在右邊）
  • 獨立性檢定的期望值：$E_{ij} = (\text{第 }i\text{ 列總和} \times \text{第 }j\text{ 欄總和}) / n$
