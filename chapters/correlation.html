關聯分析 · Pearson 相關係數

關聯分析回答的核心問題：兩個變數之間有沒有關係？關係的方向是什麼？關係有多強？

觀念 1：三種變數組合

分析兩個變數的關聯，首先看它們各自的「尺度（Scale）」——量（連續）還是質（類別）。不同組合使用不同工具。

變數 X變數 Y稱為工具
量（連續）量（連續）量量Pearson 相關係數 r
量（連續）質（類別）量質點二系列相關 / ANOVA
質（類別）質（類別）質質χ² 檢定 / Cramér's V

量 vs 質 的判斷方式

量（連續變數）：「量出來的」，有大小、可做加減。例：身高、體重、溫度、成績。

質（類別變數）：「數出來的」，只有分類標籤、無大小意義。例：性別、科系、品牌、是否通過。

觀念 2：Pearson 相關係數 r

衡量兩個連續變數之間線性關係的強度與方向。r 介於 −1 到 +1 之間，不帶任何單位。

公式

$$r = \frac{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})^2 \;\cdot\; \displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2}}$$
符號解釋
$(x_i - \bar{x})(y_i - \bar{y})$
X 偏離均值 × Y 偏離均值的乘積；兩偏差同向為正，反向為負
分子 $\sum(x_i-\bar{x})(y_i-\bar{y})$
共變異量（covariance）加總，反映兩變數「一起變動」的方向與程度
分母 $\sqrt{S_{xx} \cdot S_{yy}}$
各自離差平方和的幾何平均，做標準化使 r 不受原始單位影響
$r$
標準化後的共變異量，範圍固定在 [−1, +1]

r 的範圍與解讀

r 值範圍強度解讀
r = +1完全正相關X 增加，Y 完全等比例增加
+0.7 ≤ r < +1強正相關X 增加，Y 明顯傾向增加
+0.3 ≤ r < +0.7中等正相關趨勢存在，但資料較分散
|r| < 0.3弱或無線性關聯X 變動對 Y 幾乎沒有線性預測力
−0.7 < r ≤ −0.3中等負相關X 增加，Y 傾向減少
−1 < r ≤ −0.7強負相關X 增加，Y 明顯傾向減少
r = −1完全負相關X 增加，Y 完全等比例減少

r 描述兩個維度

方向：看正負號。正 → X 大 Y 大；負 → X 大 Y 小。

強度：看絕對值 |r|。r = +0.85 與 r = −0.85 強度相同，方向相反。

觀念 4：r 的顯著性檢定

樣本算出的 r ≠ 0，不代表母體真的有相關——可能只是抽樣巧合。 需要假設檢定確認相關是否真實存在。

假設設定（以雙尾為例）

用 ρ（rho）代表母體相關係數：

$$H_0: \rho = 0 \quad \text{（母體中無線性相關）}$$
$$H_1: \rho \neq 0 \quad \text{（母體中有線性相關）}$$

檢定統計量

$$t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}}, \quad df = n - 2$$
符號解釋
$r$
樣本 Pearson 相關係數
$n-2$
自由度，估計了 $\bar{x}$ 和 $\bar{y}$ 兩個參數，各消耗一個自由度
$\sqrt{1-r^2}$
|r| 愈大，分母愈小，t 愈大——相關越強，越容易達到顯著

範例（接上例）

r = 0.986，n = 5，α = 0.05（雙尾）。

  1. 假設：H₀: ρ = 0；H₁: ρ ≠ 0
  2. t 統計量
    $$t = \frac{0.986\sqrt{3}}{\sqrt{1-0.986^2}} = \frac{0.986 \times 1.732}{\sqrt{0.028}} = \frac{1.708}{0.167} \approx 10.24$$
  3. 臨界值：$t_{0.025,\;3} = 3.182$
  4. 結論：10.24 ≫ 3.182 → 拒絕 H₀，讀書時數與考試成績之間存在顯著線性相關。

觀念 5：相關 ≠ 因果

r 只衡量兩變數「一起變動」的程度，不代表一個「導致」另一個。

現象r直覺誤解真正原因
溺水人數 vs 冰淇淋銷量 強正相關 吃冰淇淋導致溺水？ 兩者都跟夏季高溫有關（共同原因）
兒童鞋號 vs 閱讀能力 正相關 腳大讀書好？ 兩者都跟年齡有關（共同原因）
讀書時數 vs 成績 強正相關 讀書一定導致高分？ 可能有混淆變數（如學習能力、自律性）

r 的三大限制

  1. 只偵測線性關係：r ≈ 0 不代表「完全無關」，可能存在非線性（如 U 型）關係
  2. 容易受極端值影響：一個離群點就能讓 r 從 0.9 掉到 0.3
  3. 不代表因果：相關是推論因果的必要條件，但不是充分條件
