第 4-5 章 · 機率與離散型分配

觀念 1：基本機率

機率就是「某件事發生的可能性有多大」。最直觀的算法：把有利的結果數除以所有可能的結果數。

$$P(A) = \frac{\text{有利結果數}}{\text{所有可能結果數}}$$
符號解釋
$P(A)$
事件 $A$ 發生的機率，讀作「P of A」
有利結果
「讓 $A$ 成立」的那些結果
$0 \le P(A) \le 1$
機率一定介於 0（不可能）和 1（確定）之間

範例：擲一顆公正六面骰

問：出現偶數（2、4、6）的機率是多少？

  • 所有可能結果：{1, 2, 3, 4, 5, 6}，共 6 種
  • 有利結果（偶數）：{2, 4, 6}，共 3 種
$$P(\text{偶數}) = \frac{3}{6} = \frac{1}{2} = 0.5$$

直覺驗證：偶數佔六面的一半，答案合理。

觀念 2：互補法則

「不發生」比「發生」更容易算時，用 1 減就好。

$$P(A^c) = 1 - P(A)$$
符號解釋
$A^c$
事件 $A$ 的「補集」（complement），也寫作 $\bar{A}$ 或 $A'$，意思是「$A$ 不發生」
$1 - P(A)$
因為 $P(A) + P(A^c) = 1$（所有機率加起來等於 1），所以兩邊移項

範例：擲骰不出現 6

直接算「出現 6」更簡單：$P(\text{出現 6}) = 1/6$。

$$P(\text{不出現 6}) = 1 - \frac{1}{6} = \frac{5}{6}$$

直覺驗證：六面中有五面不是 6，答案 5/6 符合。

何時用互補

當題目問「至少一次」或「不全是……」時，互補幾乎都是最省力的路：先算「一次都沒有」，再用 1 減。

觀念 3：加法法則

計算「A 或 B 至少一個發生」的機率。直接把兩個機率相加，但重疊的部分（A 和 B 同時發生）會被加了兩次，要減掉一次。

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$
符號解釋
$A \cup B$
「A 聯集 B」——A 或 B（至少一個）發生
$A \cap B$
「A 交集 B」——A 和 B 同時發生
$- P(A \cap B)$
避免重複計算：如果交集這塊區域加了兩次，就減回一次

特殊情況：互斥事件

若 A 和 B 不可能同時發生（互斥，$P(A \cap B) = 0$），公式簡化為：

$$P(A \cup B) = P(A) + P(B) \quad \text{（互斥時）}$$

範例：擲骰出現 1 或 2

{出現 1} 和 {出現 2} 互斥（不能同時是 1 又是 2）：

$$P(\text{1 或 2}) = \frac{1}{6} + \frac{1}{6} = \frac{2}{6} = \frac{1}{3}$$

範例：從 52 張牌抽一張，出現紅牌或 A

$P(\text{紅牌}) = 26/52 = 1/2$，$P(\text{A}) = 4/52 = 1/13$，$P(\text{紅 A}) = 2/52 = 1/26$。

$$P(\text{紅牌} \cup \text{A}) = \frac{1}{2} + \frac{1}{13} - \frac{1}{26} = \frac{13}{26} + \frac{2}{26} - \frac{1}{26} = \frac{14}{26} = \frac{7}{13}$$

觀念 4：條件機率

「已知 B 發生了，A 發生的機率」——知道新資訊後，縮小樣本空間再重新計算。

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$
符號解釋
$P(A \mid B)$
「在 B 已發生的條件下，A 的機率」，豎線讀作「given」（已知）
$P(A \cap B)$
A 和 B 同時發生的機率（分子：在新空間裡有利的部分）
$P(B)$
分母是「縮小後的新樣本空間」大小

範例：2×2 列聯表

一班 40 名學生，分為有無運動（行）和期末考過關（列）：

考試及格考試不及格小計
有運動18624
無運動10616
小計281240

問：已知某生有運動，考試及格的機率？

  • 「有運動」的樣本空間縮小為 24 人
  • 其中及格 18 人
$$P(\text{及格} \mid \text{有運動}) = \frac{18/40}{24/40} = \frac{18}{24} = \frac{3}{4}$$

對比「無運動及格率」= 10/16 = 5/8，有運動確實較高。

觀念 5：獨立事件

「A 發不發生，跟 B 完全沒有關係」——知道 B 的消息，對 A 的預測毫無幫助。

$$P(A \cap B) = P(A) \times P(B) \quad \text{（當 A、B 獨立）}$$
符號解釋
獨立
$P(A \mid B) = P(A)$，知道 B 不改變 A 的機率
乘法規則
獨立事件同時發生 = 各自機率相乘
注意
「互斥」≠「獨立」；互斥事件（$P(A \cap B) = 0$）當兩個機率均不為 0 時，反而是負相關的

範例：連續擲兩次公正硬幣

第一次和第二次擲幣互不影響（獨立）。求兩次都正面：

$$P(\text{正面} \cap \text{正面}) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$$

獨立的直覺驗證（列舉法）

所有可能結果：{正正, 正反, 反正, 反反}，共 4 種，各等可能。兩次都正面 = 1 種，機率確實 1/4。

三事件獨立

若 A、B、C 兩兩獨立且整體獨立，則：

$$P(A \cap B \cap C) = P(A) \times P(B) \times P(C)$$

觀念 6：二項分配

每次試驗只有「成功 / 失敗」兩種結果，做了 $n$ 次獨立試驗，計算剛好成功 $k$ 次的機率。

$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$$
符號解釋
$n$
試驗總次數（固定）
$k$
成功次數，$k = 0, 1, 2, \ldots, n$
$p$
每次成功的機率（固定，且各次獨立）
$1 - p$
每次失敗的機率，也常寫作 $q$
$\binom{n}{k}$
組合數，讀作「C(n, k)」或「n choose k」，代表從 $n$ 次試驗中選出 $k$ 次成功的排列方式有幾種
$p^k (1-p)^{n-k}$
某一種「$k$ 次成功、$n-k$ 次失敗」的排列機率

期望值與變異數

$$\mu = np \qquad \sigma^2 = np(1-p)$$

C(4, k) 速查表

以下是 $n = 4$ 時常用的組合數，熟記後算題快一倍：

$k$$\binom{4}{k}$計算方式
01$4!/(0! \cdot 4!) = 1$
14$4!/(1! \cdot 3!) = 4$
26$4!/(2! \cdot 2!) = 6$（最常出現）
34$4!/(3! \cdot 1!) = 4$
41$4!/(4! \cdot 0!) = 1$

範例：投公正硬幣 4 次，剛好 2 次正面

$n = 4,\ k = 2,\ p = 0.5$

$$P(X = 2) = \binom{4}{2} \times (0.5)^2 \times (0.5)^2 = 6 \times 0.25 \times 0.25 = \frac{6}{16} = \frac{3}{8}$$

期望值驗算

$\mu = np = 4 \times 0.5 = 2$，平均投 4 次會有 2 次正面，與直覺吻合。

適用條件（缺一不可）

  • 固定試驗次數 $n$
  • 每次只有兩種結果（成功 / 失敗）
  • 每次成功機率 $p$ 固定
  • 各次試驗相互獨立

觀念 7：波松分配

某段時間或某塊空間內，稀有事件平均發生 $\lambda$ 次，計算剛好發生 $k$ 次的機率。

$$P(X = k) = \frac{e^{-\lambda}\,\lambda^k}{k!}, \quad k = 0, 1, 2, \ldots$$
符號解釋
$\lambda$
希臘字 lambda，唯一參數，等於平均發生次數（每單位時間或空間）
$e$
自然常數，約 2.71828；$e^{-\lambda}$ 隨 $\lambda$ 增大而快速縮小
$k!$
$k$ 的階乘，$0! = 1,\ 1! = 1,\ 2! = 2,\ 3! = 6$
$\mu = \lambda$
期望值等於 $\lambda$
$\sigma^2 = \lambda$
變異數也等於 $\lambda$（期望值 = 變異數，是波松的獨特性質）

兩個最重要的特殊值

$$P(X = 0) = e^{-\lambda} \qquad P(X = 1) = \lambda e^{-\lambda}$$

這兩個不用算組合數，直接代入公式就好（$k = 0$ 時 $\lambda^0 / 0! = 1$；$k = 1$ 時 $\lambda^1 / 1! = \lambda$）。

範例：電話中心，λ = 2 通/分鐘

  • 某分鐘剛好 0 通：$P(X = 0) = e^{-2} \approx 0.135$
  • 某分鐘剛好 1 通：$P(X = 1) = 2e^{-2} \approx 0.271$
  • 某分鐘剛好 2 通：$P(X = 2) = \dfrac{e^{-2} \cdot 2^2}{2!} = \dfrac{4e^{-2}}{2} = 2e^{-2} \approx 0.271$

適用條件

  • 事件在時間或空間中「隨機且獨立」發生
  • 平均發生率 $\lambda$ 在整個觀測期間固定
  • 兩個事件不能在完全相同的瞬間發生（不重疊）

與二項分配的關係

當 $n \ge 20$ 且 $p \le 7/n$ 時，$B(n, p) \approx \text{Poisson}(\lambda = np)$，波松可作為二項的近似。
