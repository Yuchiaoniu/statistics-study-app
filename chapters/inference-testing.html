五步驟假設檢定框架（必背）
  1. 步驟 1 建立假設：寫出 H₀（虛無假設）與 H₁（對立假設）
  2. 步驟 2 選擇工具：σ已知用 Z；σ未知用 t；確認 α 與尾別
  3. 步驟 3 計算統計量：代入公式算 Z 或 t
  4. 步驟 4 臨界值：查表取得 Z_{α/2} 或 t_{α/2, df}，劃出拒絕域
  5. 步驟 5 結論：統計量落在拒絕域 → 拒絕 H₀；否則無法拒絕

觀念 1：信賴區間（Z）— σ 已知

「95% 信賴區間」的意思是：用這個方法反覆做 100 次，有 95 次的區間會包含真正的 μ。不是「μ 有 95% 機率在這個區間」——μ 是固定的，只有區間在變。

$$\bar{x} \pm Z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}$$
符號解釋
$\bar{x}$
樣本平均數，區間的中心點
$Z_{\alpha/2}$
標準常態臨界值；95% 時 α=0.05，α/2=0.025，$Z_{0.025}=1.96$
$\sigma/\sqrt{n}$
標準誤（SE）
$\pm$
往左右各延伸「誤差邊界（margin of error）」

計算範例：95% 信賴區間

已知：$\bar{x} = 100$，$\sigma = 10$，$n = 25$，信賴水準 95%（$Z_{0.025} = 1.96$）。

$$SE = \frac{10}{\sqrt{25}} = \frac{10}{5} = 2$$
$$CI = 100 \pm 1.96 \times 2 = 100 \pm 3.92 = (96.08,\ 103.92)$$
信賴水準α$Z_{\alpha/2}$
90%0.101.645
95%0.051.96
99%0.012.576
使用條件
  • 母體標準差 σ 已知
  • n ≥ 30（CLT 成立）或母體本身常態

觀念 2：信賴區間（t）— σ 未知、小樣本

實務上 σ 幾乎不會已知。當 σ 未知且樣本小（n < 30），用樣本標準差 s 替代，並改用 t 分配——t 分配比 Z 更寬，為「用 s 估計 σ 的不確定性」付出代價。

$$\bar{x} \pm t_{\alpha/2,\,df} \cdot \frac{s}{\sqrt{n}}, \quad df = n - 1$$
符號解釋
$s$
樣本標準差（用來估計 σ）
$t_{\alpha/2,\,df}$
t 分配臨界值，需要同時指定顯著水準 α/2 與自由度 df
$df = n-1$
自由度（degrees of freedom）；用一個限制（計算 $\bar{x}$）後剩下 n−1 個「自由」的資料點

計算範例：95% 信賴區間（t）

已知：$\bar{x} = 50$，$s = 4$，$n = 9$，95%（$t_{0.025,\,8} = 2.306$）。

$$SE = \frac{s}{\sqrt{n}} = \frac{4}{\sqrt{9}} = \frac{4}{3} \approx 1.333$$
$$CI = 50 \pm 2.306 \times \frac{4}{3} = 50 \pm 3.075 = (46.92,\ 53.08)$$

t vs Z：何時用哪個？

條件工具
σ 已知 Z 分配
σ 未知，n ≥ 30 t 分配（大樣本時 t ≈ Z）
σ 未知，n < 30，母體常態 t 分配（必用）
σ 未知，n < 30，母體非常態 無法直接用參數檢定

觀念 3：Z 假設檢定（單樣本）— σ 已知

有一個數字宣稱「母體均值等於 μ₀」，我們用樣本數據來判斷：這個宣稱合理嗎？

$$Z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$
符號解釋
$\mu_0$
H₀ 宣稱的母體均值（虛無值）
$\bar{x} - \mu_0$
樣本均值與假設值的差距
$\sigma / \sqrt{n}$
標準誤（SE），用來衡量差距「值幾個標準誤」
$Z$
Z 統計量：差距除以標準誤，得到「距離幾個標準差」

完整五步驟範例

已知 σ = 10，抽 n = 25 得 x̄ = 104。H₀: μ = 100，H₁: μ ≠ 100，α = 0.05（雙尾）。

  1. 建立假設：H₀: μ = 100；H₁: μ ≠ 100
  2. 選擇工具：σ 已知，用 Z 檢定；α = 0.05，雙尾，臨界值 ±1.96
  3. 計算統計量：
    $$Z = \frac{104 - 100}{10 / \sqrt{25}} = \frac{4}{10/5} = \frac{4}{2} = 2.0$$
  4. 臨界值：$Z_{0.025} = 1.96$；拒絕域 $|Z| > 1.96$
  5. 結論：$|2.0| = 2.0 > 1.96$，落在拒絕域 → 拒絕 H₀，有顯著證據顯示 μ ≠ 100
雙尾 vs 單尾
H₁尾別拒絕條件（α=0.05）
μ ≠ μ₀雙尾|Z| > 1.96
μ > μ₀右尾Z > 1.645
μ < μ₀左尾Z < −1.645

觀念 4：t 假設檢定（單樣本）— σ 未知

結構與 Z 檢定完全相同，差別在於：用 s 替代 σ、查 t 表取得臨界值。

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}, \quad df = n - 1$$
符號解釋
$s$
樣本標準差（替代未知的 σ）
$df = n-1$
自由度，用於查 t 表的第二個索引

完整五步驟範例

已知 s = 6，抽 n = 9 得 x̄ = 54。H₀: μ = 50，H₁: μ ≠ 50，α = 0.05（雙尾）。

  1. 建立假設：H₀: μ = 50；H₁: μ ≠ 50
  2. 選擇工具：σ 未知，用 t 檢定；df = 9 − 1 = 8
  3. 計算統計量：
    $$t = \frac{54 - 50}{6 / \sqrt{9}} = \frac{4}{6/3} = \frac{4}{2} = 2.0$$
  4. 臨界值：查 t 表 $t_{0.025,\,8} = 2.306$；拒絕域 $|t| > 2.306$
  5. 結論：$|2.0| = 2.0 < 2.306$，未落在拒絕域 → 無法拒絕 H₀，無顯著證據顯示 μ ≠ 50
t 臨界值 > Z 臨界值 的原因

用 s 估計 σ 帶來額外不確定性，t 分配比 Z 更寬（尾巴更厚），所以臨界值更大。n 越大，df 越大，t 分配越接近 Z（df → ∞ 時完全一致）。

觀念 5：雙母體獨立樣本檢定（Case 4~7）

比較兩組的母體均值是否相同。根據「σ 是否已知」與「樣本大小」決定用 Z 或 t，再視等變異與否選擇 Pooled t 或 Welch t。

Case 4：σ₁²、σ₂² 都已知 → Z 檢定

$$Z = \frac{(\bar{x}_1 - \bar{x}_2) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}}$$

H₀ 通常設 μ₁ − μ₂ = 0，代入後分子就是 $\bar{x}_1 - \bar{x}_2$。

Case 5：σ 未知，大樣本（n₁ ≥ 30 且 n₂ ≥ 30）→ Z 近似

$$Z = \frac{(\bar{x}_1 - \bar{x}_2) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}$$

σ 未知但樣本夠大，以 s 替代 σ，CLT 保證 Z ≈ 標準常態分配。

Case 6/7 前置：F 檢定（變異數齊一性）

$$F = \frac{s_1^2}{s_2^2} \quad (\text{令 } s_1^2 \ge s_2^2), \quad df_1 = n_1 - 1,\ df_2 = n_2 - 1$$

若 $F_0 \leq F_{\alpha/2,\,df_1,\,df_2}$（不顯著）→ 走 Case 6；若超過臨界值（顯著）→ 走 Case 7。

Case 6：小樣本，σ₁² = σ₂² → Pooled t

$$s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2}$$
$$t = \frac{(\bar{x}_1 - \bar{x}_2) - (\mu_1 - \mu_2)}{s_p\sqrt{\dfrac{1}{n_1}+\dfrac{1}{n_2}}}, \quad df = n_1 + n_2 - 2$$
符號解釋
$s_p^2$
合併變異數（pooled variance）——對兩組 s² 做加權平均
$s_p$
合併標準差，$s_p = \sqrt{s_p^2}$
$df = n_1+n_2-2$
合併 t 的自由度（兩組各用掉 1 個自由度）

Case 7：小樣本，σ₁² ≠ σ₂² → Welch t

$$t = \frac{(\bar{x}_1 - \bar{x}_2) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}$$

自由度用 Satterthwaite 近似公式（結果四捨五入取整數）：

$$df = \frac{\left(\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}\right)^2}{\dfrac{\left(\dfrac{s_1^2}{n_1}\right)^2}{n_1-1} + \dfrac{\left(\dfrac{s_2^2}{n_2}\right)^2}{n_2-1}}$$
符號解釋
$s_1^2,\ s_2^2$
兩組的樣本變異數
$df$
Welch t 的近似自由度（Satterthwaite 公式），計算後四捨五入

完整範例（Case 6）：A 組 vs B 組

A 組：$n_1=10,\ \bar{x}_1=1230,\ s_1^2=128$；B 組：$n_2=10,\ \bar{x}_2=1200,\ s_2^2=72$。H₀: μ₁ = μ₂，α = 0.05（雙尾）。

  1. F 檢定（先令大的在分子）：
    $$F = \frac{128}{72} \approx 1.78, \quad df_1 = 9,\ df_2 = 9$$
    查 F 表（α=0.05，df₁=9，df₂=9），臨界值 ≈ 3.18。1.78 < 3.18 → 不顯著，走 Case 6。
  2. 合併變異數：
    $$s_p^2 = \frac{9 \times 128 + 9 \times 72}{18} = \frac{1800}{18} = 100, \quad s_p = 10$$
  3. t 統計量：
    $$t = \frac{1230 - 1200}{10\sqrt{\frac{1}{10}+\frac{1}{10}}} = \frac{30}{10 \times 0.4472} \approx 6.71$$
  4. 臨界值：$t_{0.025,\,18} = 2.101$；拒絕域 $|t| > 2.101$
  5. 結論：$6.71 \gg 2.101$ → 拒絕 H₀，A、B 兩組均值有顯著差異

觀念 6：Case 8 — 配對 t 檢定（Paired t-test）

兩筆數據來自同一受試者的兩次測量（前測／後測、左右手、雙胞胎），資料本身不獨立，不能套用兩樣本 t。做法是先把每對的差值 $d_i$ 算出來，再對差值做一次單樣本 t 檢定。

配對 vs 獨立：先判斷，再選工具

情境描述判斷依據正確工具
同一批人接受訓練前後測驗 同一受試者，兩個時間點 配對 t
A 班與 B 班各自受測 不同受試者，互相獨立 兩樣本 t
同一批機器維修前後的效率 同一對象，兩個時間點 配對 t
左手與右手的握力（同一人量兩次） 同一受試者的兩種條件 配對 t

計算步驟

  1. 對每一對計算差值（順序要固定，全程一致）：$d_i = x_{1i} - x_{2i}$
  2. 計算差值的平均數：$$\bar{d} = \frac{\sum_{i=1}^{n} d_i}{n}$$
  3. 計算差值的標準差：$$s_d = \sqrt{\frac{\sum_{i=1}^{n}(d_i - \bar{d})^2}{n-1}}$$
  4. 代入 t 統計量：
$$t = \frac{\bar{d}}{s_d / \sqrt{n}}, \quad df = n - 1$$
符號解釋
$d_i$
第 $i$ 對的差值（條件 A 減條件 B，順序自訂但全程統一）
$\bar{d}$
n 個差值的平均數，H₀ 要檢定的是 $\mu_d = 0$
$s_d$
差值的樣本標準差
$s_d / \sqrt{n}$
差值的標準誤（SE of differences）
$df = n - 1$
自由度以「對數 n」計算，不是受試者總人次

為什麼配對設計比兩樣本 t 更有效率？

兩樣本 t 的分母包含「個體差異」——基準心率本就高的人，前後都高；基準低的人前後都低。這個個體差異會讓合併標準差變大，t 值縮小，更難顯著。配對 t 把每個人自己的前後差值相減，個體基準自動抵消，分母 $s_d$ 只反映「差值本身的變異」，不受個體差異污染。同樣 n 個受試者，配對設計的統計檢定力（power）更高。
