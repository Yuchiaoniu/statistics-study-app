假設檢定總覽

費雪把科學實驗轉化成一場法庭辯論：H₀ 是「無罪推定」，統計量是「證據強度」， α 是「定罪標準」。這個心智模型讓「效果是否顯著」這件事從直覺判斷變成可量化的決策。

法庭審判隱喻

⚖️ 把假設檢定想成一場刑事訴訟
法庭概念
無罪推定
被告在被證明有罪之前，預設是無罪的。
統計對應
虛無假設 H₀
預設「沒有效果、沒有差異」。這是我們試圖推翻的起點。
法庭概念
起訴主張
檢察官認為被告有罪，提出主張。
統計對應
對立假設 H₁
研究者的主張：效果存在、有差異。這是我們想要證明的。
法庭概念
呈堂證據
物證、證詞，越有說服力越好。
統計對應
檢定統計量（Z / t / F / χ²）
樣本算出的數字，代表「如果 H₀ 為真，觀測到這個結果的可能性有多低」。
法庭概念
定罪標準
「排除合理懷疑」——多高的確信度才能定罪。
統計對應
顯著水準 α
允許犯「冤枉好人（型 I 錯誤）」的最大機率。通常設 0.05 或 0.01。
法庭概念
判決
有罪 / 無罪。注意：無罪不代表清白，只代表證據不足。
統計對應
拒絕 / 不拒絕 H₀
「不拒絕 H₀」不代表 H₀ 為真，只代表樣本證據不足以推翻它。

五步驟解題流程

  1. 1
    建立假設
    H₀ 永遠用等號（=、≤、≥）。H₁ 的方向決定是單尾還是雙尾： 「有無差異」→ ≠（雙尾）；「是否大於」→ >（右單尾）；「是否小於」→ <（左單尾）。
    H₀: μ_A − μ_B = 0　　H₁: μ_A − μ_B ≠ 0　（雙尾）
  2. 2
    選擇工具
    根據樣本大小、是否知道 σ、幾組比較、資料型態，選 Z / t / F / χ²。 （詳見統計決策樹）
  3. 3
    計算統計量
    把樣本數字代入公式，算出 Z / t / F / χ² 的數值。 這個數字代表：假設 H₀ 為真，觀察到這麼極端結果的距離有多遠（用標準誤當單位）。
    Z = (x̄ − μ₀) / (σ/√n) = (401800 − 388000) / 4850.62 ≈ 2.845
  4. 4
    確定臨界值
    查 Z / t / F / χ² 表，找到「在 α 水準下允許的最大值」。 雙尾時 α 平分成兩邊，各 α/2。
    α = 0.05，雙尾 → 查 Z 表：Z_0.025 = 1.96
  5. 5
    決策與結論
    統計量落入拒絕域（超過臨界值）→ 拒絕 H₀，結論顯著。
    統計量未落入拒絕域 → 不拒絕 H₀，樣本證據不足。
    |Z| = 2.845 > 1.96 → 拒絕 H₀ → 兩市平均收入有顯著差異（α=5%）

三種決策方法

拒絕 H₀ 有三種等價方法，結論完全一致，切入角度不同：

方法決策規則優勢
① 臨界值法 |檢定統計量| > 臨界值 → 拒絕 H₀ 圖形直觀，容易理解
② p 值法 p 值 < α → 拒絕 H₀ 統計軟體標準輸出，可跨研究比較
③ 信賴區間法 μ₀ 落在 (1−α) CI 外 → 拒絕 H₀ 同時提供估計範圍，資訊最豐富

方法 ②：p 值法（p-value Method）

p 值定義：假設 H₀ 為真，觀察到目前樣本結果（或更極端的結果）的機率。

尾別p 值計算
右尾（H₁: μ > μ₀）p = P(Z ≥ z₀) = 1 − Φ(z₀)
左尾（H₁: μ < μ₀）p = P(Z ≤ z₀) = Φ(z₀)
雙尾（H₁: μ ≠ μ₀）p = 2 × P(Z ≥ |z₀|) = 2(1 − Φ(|z₀|))
決策規則：
p 值 < α  → 拒絕 H₀（結果在 H₀ 下太稀有，顯著）
p 值 ≥ α  → 不拒絕 H₀（結果在 H₀ 下屬合理範圍，不顯著）

計算範例

右尾檢定：z₀ = 2.35，α = 0.05

p 值 = P(Z ≥ 2.35) = 1 − Φ(2.35) ≈ 1 − 0.9906 = 0.0094

p = 0.0094 < α = 0.05 → 拒絕 H₀（與臨界值法結論相同）

反常識點：p 值越小，越有理由拒絕 H₀；p = 0.001 遠比 p = 0.04 更強烈地反對 H₀。

方法 ③：信賴區間法（CI Method）

建立 (1−α) 信賴區間，觀察 H₀ 所設定的 μ₀ 是否落在區間內：

  • μ₀ 落在 CI 之外 → 拒絕 H₀
  • μ₀ 落在 CI 之內 → 不拒絕 H₀
Case 1（σ 已知）95% 信賴區間：

        σ
x̄ ± 1.96 · ──
       √n

Case 3（σ 未知，n < 30）95% 信賴區間：

        s
x̄ ± t_{α/2, df} · ──
        √n

計算範例

x̄ = 172，σ = 10，n = 36，μ₀ = 170，α = 0.05

SE = 10/√36 ≈ 1.667

95% CI：172 ± 1.96 × 1.667 = (168.73, 175.27)

μ₀ = 170 落在 (168.73, 175.27) 內 → 不拒絕 H₀
等價性：信賴區間法（雙尾）與雙尾臨界值法在同一 α 下結論完全相同。 信賴區間的附加價值：不只是「拒絕/不拒絕」，還能看出 μ 可能的合理範圍。

型 II 誤差 β 與檢定力（Power）

型 II 誤差 β 深入說明

β = P(不拒絕 H₀ | H₀ 為假，真實 μ = μₐ)

白話：效果真的存在，但實驗沒有抓到它的機率。需要指定「真實的 μ 是多少（μₐ）」才能計算。

影響 β 的四個因素

因素變動β 的變化原因
樣本量 n↑ 增大↓ 減小SE 縮小，更容易偵測差異
顯著水準 α↑ 放寬↓ 減小拒絕域變大，更容易拒絕 H₀
真實差距 |μₐ − μ₀|↑ 增大↓ 減小差距越大越容易偵測
母體標準差 σ↑ 增大↑ 增大雜訊增加，訊號更難浮現
α 與 β 的拉扯：降低 α（更嚴格）→ 型 I 錯誤減少，但 β 上升（型 II 錯誤增加）。 兩者無法同時無限縮小——唯一的辦法是增大 n。

檢定力（Power = 1 − β）

Power = 1 − β = P(正確拒絕 H₀ | H₀ 為假)

白話：「我的實驗有多大把握能抓到真實的效果？」學術研究通常要求 Power ≥ 0.80。

Power 值意義
0.20極弱：五次只有一次抓到，幾乎靠運氣
0.50猜硬幣水準，不適合用於研究
0.80一般學術研究的最低門檻（APA 建議）
0.95+高檢定力，適合醫學試驗等高風險決策

提高 Power 的四個方法

  1. 增大樣本 n（最常用，SE = σ/√n 縮小）
  2. 放寬 α（從 0.01 改為 0.05，但型 I 錯誤機率上升）
  3. 選擇效果更大的介入（μₐ 與 μ₀ 差距越大越好偵測）
  4. 減少量測雜訊 σ（改進實驗設計、使用精確量測工具）
