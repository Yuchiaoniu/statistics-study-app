統計學專詞

不重複地列出所有在講義中出現過的專詞，依類別分組。每個專詞含中英對照與口語化解釋。

1. 基礎概念
隨機變數 Random Variable
會隨機取不同數值的變數，通常用大寫字母 X、Y 表示。它本身不是一個固定的數，而是「會隨實驗結果變化的數量」。
機率 Probability
一件事發生的可能性，用 0 到 1 之間的數值表示。0 = 絕不發生、1 = 必然發生、0.5 = 一半機率。
樣本空間 Sample Space
一個隨機實驗所有可能結果的集合，常用 $\Omega$ 表示。例：丟一顆骰子的樣本空間是 $\{1,2,3,4,5,6\}$。
事件 Event
樣本空間的子集合，代表我們關心的「某些結果」。例：擲骰子「出現偶數」是事件 $\{2,4,6\}$。
機率分配 Probability Distribution
把「總機率 = 1」這塊餅分配給所有可能結果的規則。本質上是一個函數（輸入結果，輸出機率或密度）。
母體 Population
研究者感興趣的「所有測量值」的集合。例如：想了解全台灣樹的碳儲量，母體就是全台每棵樹的碳儲量資料。
樣本 Sample
從母體中抽出的一個子集，用來「代表」母體做推論。母體通常太大無法全測，所以靠樣本來「猜」母體長相。
2. 離散 vs 連續
離散型隨機變數 Discrete Random Variable
只能取「可數」個值（例如：整數 0, 1, 2, ...）。例：丟硬幣 10 次正面數、書中錯字數。
連續型隨機變數 Continuous Random Variable
可以取數線上某段區間內「不可數」個值。例：等公車時間、體重、溫度。
可數 / 不可數 Countable / Uncountable
可數 = 可以一個一個列舉出來（如 $1, 2, 3, \ldots$）；不可數 = 列不完（如 $[0, 1]$ 區間內所有實數）。
機率質量函數 Probability Mass Function (PMF)
離散型專用。輸入 $x$、輸出 $P(X=x)$，函數值就是機率本身。
機率密度函數 Probability Density Function (PDF)
連續型專用。輸入 $x$、輸出該點的「密度」。注意：密度不是機率！ 機率要積分後才出來。
累積分配函數 Cumulative Distribution Function (CDF)
$F(x) = P(X \le x)$。「到 $x$ 為止累積了多少機率」。離散型是階梯函數，連續型是平滑曲線。
機率密度 Probability Density
「每單位寬度的機率」，類似物理的「密度 = 質量/體積」。要乘上寬度 $dx$ 才會變成機率。
階梯函數 Step Function
離散型 CDF 的圖形樣貌。每個可能值處會「跳一階」，跳高度 = 該點 PMF。
跳點 Jump Point
離散型 CDF 在可能值 $x_i$ 處的不連續位置。$P(X = x_i) = F(x_i) - F(x_i^-)$。
3. 分配的特徵數
期望值 Expected Value
$E(X)$ 或 $\mu$，分配的「平均位置」。離散型 $E(X) = \sum x \cdot P(X=x)$；連續型 $E(X) = \int x f(x)\, dx$。
變異數 Variance
$\mathrm{Var}(X)$ 或 $\sigma^2$，衡量分配的「離散程度」。值越大代表資料越分散。
標準差 Standard Deviation, SD
$\sigma = \sqrt{\mathrm{Var}(X)}$，變異數的平方根，跟原始資料同單位，比變異數更好詮釋。
注意分母不同：母體標準差 $\sigma$ 分母為 $N$；樣本標準差 $s$ 分母為 $n-1$（不偏估計）。
$s = \sqrt{\frac{1}{n-1}\sum (x_i - \bar X)^2}$
動差母函數 Moment Generating Function (MGF)
$M(t) = E(e^{tX})$，是個「生成器」：對它求 1 階導數得 $E(X)$、2 階導數得 $E(X^2)$。
線性性質 Linearity
$E(aX+b) = aE(X) + b$；$\mathrm{Var}(aX+b) = a^2 \mathrm{Var}(X)$。注意變異數中「+b」不影響但「a」要平方。
4. 機率公理與運算規則
機率公理 Probability Axioms (Kolmogorov)
三條：① 非負性 $P(A) \ge 0$、② 規範性 $P(\Omega) = 1$、③ 可加性（互斥事件 $P(A \cup B) = P(A) + P(B)$）。
條件機率 Conditional Probability
$P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$。「在 $B$ 發生的條件下 $A$ 發生」的機率。
獨立性 Independence
$A$、$B$ 獨立 ⇔ $P(A \cap B) = P(A) P(B)$。等價於 $P(A \mid B) = P(A)$（「$B$ 是否發生不影響 $A$」）。
互斥事件 Mutually Exclusive
$A \cap B = \emptyset$，兩事件不可能同時發生。注意：互斥 ≠ 獨立（兩非零事件若互斥則必不獨立）。
貝氏定理 Bayes' Theorem
$P(A \mid B) = \dfrac{P(B \mid A) P(A)}{P(B)}$。用「事後條件」反推「事前機率」。
全機率公式 Law of Total Probability
$P(B) = \sum_i P(B \mid A_i) P(A_i)$，把 $B$ 的機率拆解為各種情境的加權和。
5. 離散型分配
二項分配 Binomial Distribution, $B(n, p)$
$n$ 次獨立伯努利試驗中成功次數。例：丟硬幣 10 次正面數。
波松分配 Poisson Distribution, $\mathrm{Poisson}(\lambda)$
單位時間/空間內隨機事件發生次數。例：每小時客服電話數。特色：$E(X) = \mathrm{Var}(X) = \lambda$。
超幾何分配 Hypergeometric Distribution
「不放回」抽樣的成功數。例：從 20 顆球（8 紅 12 白）抽 5 顆中的紅球數。對應放回版本的二項分配。
幾何分配 Geometric Distribution
「首次成功」前的試驗次數。例：第幾次丟硬幣才出現正面。具有無記憶性。
負二項分配 Negative Binomial Distribution
「第 $r$ 次成功」前的試驗次數。幾何分配是 $r=1$ 的特例。
波松過程 Poisson Process
事件依固定速率 $\lambda$ 隨機發生的過程。次數服從波松分配，等待時間服從指數分配。
波松近似二項 Poisson Approximation to Binomial
當 $n \ge 20$ 且 $np \le 7$ 時，$B(n, p) \approx \mathrm{Poisson}(\lambda = np)$，計算更方便。
6. 連續型分配
連續型均勻分配 Continuous Uniform Distribution, $U(a, b)$
X 在 $[a, b]$ 內每個位置密度相同的分配。PDF 是水平直線、CDF 是斜直線。例：等公車時間。
常態分配 Normal Distribution, $N(\mu, \sigma^2)$
對稱鐘形曲線，自然界與測量誤差最常見。$\mu$ 控制位置、$\sigma$ 控制胖瘦。
標準常態分配 Standard Normal, $N(0, 1)$
$\mu = 0, \sigma = 1$ 的常態。任意常態可透過 $Z = (X-\mu)/\sigma$ 轉成標準常態。
高斯分配 Gauss Distribution
常態分配的別名，紀念 Gauss 對此分配的研究貢獻。另有「鐘形分配」（因外型）。
反曲點 Inflection Point
曲線的凹凸方向改變的位置。常態曲線在 $\mu - \sigma$ 與 $\mu + \sigma$ 處各有一個反曲點。
中位數 Median, $M_e$
把資料由小排到大後位於正中央的值。常態分配中 $M_e = \mu$（同等於平均數）。
眾數 Mode, $M_o$
資料中出現最頻繁的值。常態分配中 $M_o = \mu = M_e$（三者相等是常態獨特特徵）。
Z 化 / 標準化 Z-score Transformation
把 $X \sim N(\mu, \sigma^2)$ 透過 $Z = (X-\mu)/\sigma$ 轉成 $Z \sim N(0,1)$ 的過程。
標準常態分配表 Z Table / Standard Normal Table
事先建好的 $N(0,1)$ 累積機率對照表。任意常態先 Z 化後就能查此表得機率。
大數法則 Law of Large Numbers
當樣本數 $n$ 趨近無窮，樣本平均數會收斂到母體平均數。是 CLT 的近親。
Z 分配對稱性 Symmetry of Z
標準常態以 0 為中心對稱：$P(Z > 0) = P(Z < 0) = 0.5$、$P(-z < Z < 0) = P(0 < Z < z)$、$P(Z < -z) = P(Z > z)$。是查表必備的轉換。
反查 z 值 Inverse Z Lookup
給定機率反推 z 值的過程。例：題目給「前 15%」要找 z，先換成 $P(0 \le Z \le z) = 0.35$ 再從 Z 表反查得 z ≈ 1.04。
常態近似二項 Normal Approximation to Binomial
當 $np \ge 5$ 且 $n(1-p) \ge 5$ 時，$B(n,p) \approx N(np, np(1-p))$。讓二項計算可用 Z 表完成。
指數分配 Exponential Distribution, $\mathrm{Exp}(\lambda)$
波松過程「事件之間的等待時間」。$\lambda$ 為發生率。特色：具有無記憶性。
卡方分配 Chi-square Distribution, $\chi^2$
$n$ 個獨立 $N(0,1)$ 的平方和。用於變異數推論、適合度檢定。
t 分配 Student's t-distribution
小樣本（母體 $\sigma$ 未知）做平均數推論時用。比常態尾巴稍胖。
F 分配 F-distribution
兩個卡方分配（各除以自由度）之比。用於變異數比較、ANOVA。
7. 連續型核心性質
單點機率為 0
連續型 $P(X = x_0) = 0$ 永遠成立，因為「點」的區間長度為 0。所以連續型「≤」和「<」可以互換。
三大性質
合法的 PDF 必須滿足：① $f(x) \ge 0$、② $\int f(x)\,dx = 1$、③ $P(c \le X \le d) = \int_c^d f(x)\,dx$。
標準化 Standardization
$Z = \dfrac{X - \mu}{\sigma}$，把任意常態變成標準常態 $N(0,1)$。先中心化（−μ）再縮放（÷σ）。
無記憶性 Memoryless Property
$P(X > s+t \mid X > s) = P(X > t)$。「過去多久不影響未來等待時間」。只有指數分配與幾何分配具有。
68-95-99.7 法則 Empirical Rule
常態分配中：$\mu \pm \sigma$ 涵蓋 68%、$\mu \pm 2\sigma$ 涵蓋 95%、$\mu \pm 3\sigma$ 涵蓋 99.7%。
8. 抽樣與推論（先備觀念）
樣本平均數 Sample Mean
$\bar X = \dfrac{1}{n}\sum X_i$，是個隨機變數，其分配稱為「抽樣分配」。
抽樣分配 Sampling Distribution
樣本統計量（如 $\bar X$）本身的機率分配。是統計推論的核心。
標準誤 Standard Error, SE
「樣本平均數 $\bar X$ 的標準差」，不是個別資料的標準差！
$SE = \sigma/\sqrt n$（σ 已知）或 $SE = s/\sqrt n$（σ 未知）。
除以 $\sqrt n$ 的直覺：抽 100 人算平均，誤差會比抽 1 人少 10 倍（$\sqrt{100}=10$）。
中央極限定理 Central Limit Theorem (CLT)
當 $n$ 夠大（一般 $n \ge 30$），無論母體分配，$\bar X$ 近似服從 $N(\mu, \sigma^2/n)$。讓常態變得「處處可用」。
自由度 Degrees of Freedom, $\nu$ or df
樣本中「獨立資訊個數」。單樣本平均數推論時 $\nu = n - 1$（因為平均數已用掉一個自由度）。查 t 表必備的參數。
t 分配 Student's t-distribution, $t_\nu$
由 W. S. Gosset 以筆名「Student」發表。當小樣本（$n < 30$）且母體 σ 未知時，用樣本標準差 $S$ 取代 σ 後的統計量服從 t 分配。形狀像常態但尾巴較胖；自由度 $\nu \to \infty$ 時 $t \to Z$。
臨界值 Critical Value, $t_{\nu, \alpha}$
在 t 分配（自由度 ν）下，右尾面積為 α 對應的 t 值。即 $P(t \ge t_{\nu, \alpha}) = \alpha$。例：$t_{10, 0.05} = 1.8125$ 表示「自由度 10 時，5% 機率落在 t > 1.8125」。
信賴水準 Confidence Level, $1-\alpha$
建構信賴區間時所選的把握度。常見 95%（$\alpha = 0.05$）、99%（$\alpha = 0.01$）。雙尾檢定時 α 平均分配到兩側，故查表用 $\alpha/2$。
9. 假設檢定核心詞彙
個別資料 $x_i$ i-th observation
樣本中「第 $i$ 個」資料點。下標 $i$ 是編號（1, 2, ..., n），不是次方。例：5 位學生身高 170, 165, 178, 172, 169，則 $x_1=170, x_2=165, \ldots, x_5=169$。寫公式時用 $\sum x_i$ 比寫 $x_1+x_2+\ldots+x_n$ 簡潔。
假設檢定 Hypothesis Testing
用樣本資料判斷母體是否符合某假設的統計流程，標準五步驟：（1）設假設、（2）選 α、（3）算檢定統計量、（4）查臨界值、（5）作結論。
虛無假設 Null Hypothesis, $H_0$
「沒有變化、沒有效果、沒有差異」的預設立場。檢定的目的是看樣本能否提供足夠證據「推翻」它。例：$H_0: \mu = 65$（體重沒變）。
對立假設 Alternative Hypothesis, $H_1$ or $H_a$
「想證明的事」。$H_1$ 寫對了，檢定才能朝你期望的方向走。三種寫法：$\neq$（雙尾）、$>$（單尾右）、$<$（單尾左）。例：「是否增加」→ $H_1: \mu > 65$。
顯著水準 $\alpha$ Significance Level
「容許自己誤判的最大冒險率」，由研究者事先決定。技術上是「型 I 誤差的最大機率」。
冒險比喻：α = 5% 就像「我願意賭 95% 的把握，剩下 5% 的機率我會誤判」。α 越小越保守，但越難拒絕 $H_0$。
常用值：0.10 / 0.05（最常見）/ 0.01 / 0.001。
信賴水準 $1-\alpha$ Confidence Level, CL
顯著水準的對立面，「有把握的程度」。$\alpha + (1-\alpha) = 1$。例：α = 0.05 ⇔ 信賴水準 = 0.95（95% 把握）。信賴區間是「用這個方法做 100 次，長期下來會有 (1−α)×100% 次包住真值」。
檢定統計量 Test Statistic
不是單位，是「一個數字」——用樣本算出的「分數」，用來決定是否拒絕 $H_0$。
常見類型：Z 統計量、t 統計量、卡方統計量、F 統計量。例：$Z = (\bar X - \mu_0)/(s/\sqrt n)$ 算出的值（如 2.5）就是檢定統計量。
拒絕域 Rejection Region / Critical Region
「檢定統計量落在這裡就拒絕 $H_0$」的範圍，由臨界值與檢定方向決定。
單尾右尾：$Z > Z_\alpha$；單尾左尾：$Z < -Z_\alpha$；雙尾：$|Z| > Z_{\alpha/2}$。
保留域 Retention / Acceptance Region
拒絕域的「補集」——檢定統計量落在這裡就不拒絕 $H_0$。
⚠ 重要：「保留 $H_0$」不等於「接受 $H_0$ 是真的」！只是「證據不足以推翻」。類似法庭：判「無罪」不代表「無辜」，可能只是證據不足。
單尾檢定 One-tailed / One-sided Test
$H_1$ 寫成 $>$ 或 $<$（單向關心）。拒絕域只在一邊。題目關鍵字：「增加 / 減少 / 提升 / 超過 / 不足」。α=0.05 時臨界值 $Z = \pm 1.645$。
雙尾檢定 Two-tailed / Two-sided Test
$H_1$ 寫成 $\neq$（兩向都關心）。拒絕域分在兩邊各 α/2。題目關鍵字：「改變 / 不同」。α=0.05 時臨界值 $Z = \pm 1.96$（每側分 2.5%）。
Z 檢定 Z-test
用 Z 統計量做的假設檢定，適用：（a）σ 已知，或（b）大樣本 $n \ge 30$（用 $s$ 近似 σ）。
t 檢定 t-test
用 t 統計量做的假設檢定，適用：σ 未知且小樣本 $n < 30$。臨界值要查 t 表（看自由度 $\nu = n-1$）。
p-value p-value
「如果 $H_0$ 真的成立，看到目前樣本（或更極端）的機率」。p 越小代表證據越強。
決策規則：$p < \alpha$ → 拒絕 $H_0$；$p \ge \alpha$ → 保留 $H_0$。
例：p = 0.0062 表示「H₀ 為真時看到這種樣本的機率只有 0.62%」，證據相當有力。
型 I 誤差 Type I Error
$H_0$ 實際為真，但你卻拒絕了它。「冤枉好人」。發生機率 = α。
例：法庭把無辜的人判有罪。
型 II 誤差 Type II Error
$H_0$ 實際為假，但你卻沒拒絕。「放過壞人」。發生機率記為 $\beta$。
例：法庭把真兇判無罪。
檢定力 Statistical Power, $1-\beta$
「正確抓出 $H_0$ 為假」的能力 = $1-\beta$。提升檢定力的方法：增加樣本數 $n$、放寬 α、效應量越大越容易抓。

公式速查

所有講義出現過的公式，依分配分組。每條公式底下都有符號逐項解釋。

通用公式（適用所有分配）

機率公理（規範性）

$$\sum_x P(X=x) = 1 \quad \text{或} \quad \int_{-\infty}^{\infty} f(x)\,dx = 1$$
符號解釋
$P(X=x)$
離散型機率質量函數
$f(x)$
連續型機率密度函數
$\sum$ 與 $\int$
離散用加總、連續用積分，本質都是「把所有機率加起來」

累積分配函數 CDF

$$F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\,dt$$
符號解釋
$F(x)$
累積分配函數，到 $x$ 為止累積的機率
$\int_{-\infty}^{x}$
從負無窮積分到 $x$（PDF 曲線下面積）
$f(t)$
PDF（用 $t$ 做積分變數避免和上限 $x$ 衝突）

離散型單點機率拆解

$$P(X = x_0) = F(x_0) - F(x_0^-)$$
符號解釋
$x_0^-$
從左邊逼近 $x_0$，「跳之前的瞬間」（負號不是次方，是左極限）
$F(x_0) - F(x_0^-)$
離散型 = 跳的高度（即 PMF）；連續型 = 0（CDF 連續無跳）

區間機率（神級公式）

$$P(a \le X \le b) = F(b) - F(a)$$
符號解釋
$F(b), F(a)$
CDF 在兩端點的值
連續型 ≤ 與 < 等價
因 $P(X=a)=P(X=b)=0$，加不加等號不影響

黎曼和（積分本質）

$$\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{i=1}^n f(x_i)\,\Delta x$$
符號解釋
$\Delta x$
每根長方形的寬度（$\Delta$ = 微小差異）
$f(x_i)\,\Delta x$
第 $i$ 根長方形的面積
$\lim_{n \to \infty}$
讓根數趨近無限多、寬度趨近 0

連續型期望值

$$\mu = E(X) = \int_{-\infty}^{\infty} x \cdot f(x)\,dx$$
符號解釋

連續型變異數

$$\sigma^2 = \mathrm{Var}(X) = \int_{-\infty}^{\infty} (x-\mu)^2 \cdot f(x)\,dx$$
$$\mathrm{Var}(X) = E(X^2) - [E(X)]^2 \quad \text{（化簡）}$$
符號解釋
$(x - \mu)^2$
每個 $x$ 距離平均的偏差平方
$E(X^2)$
$X$ 平方後的期望值 $= \int x^2 f(x)\,dx$
化簡式
實戰好用：先算 $E(X^2)$，再減 $[E(X)]^2$

線性性質

$$E(aX + b) = a\,E(X) + b,\quad \mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)$$
符號解釋
$a, b$
常數（不是隨機變數）
$b$ 對 Var 無影響
因為「平移」不改變分散程度
$a$ 要平方

符號解釋

$p$

符號解釋

$k!$

PDF

符號解釋
$\mu$
平均數，曲線中心
$\sigma$

$\dfrac{1}{\sigma\sqrt{2\pi}}$

$\exp(\cdot)$

$(x-\mu)^2$

標準化

$$Z = \frac{X - \mu}{\sigma},\quad Z \sim N(0, 1)$$
符號解釋
$Z$
標準化後的變數，服從 $N(0, 1)$
$X - \mu$
中心化：把平均移到 0

縮放：把標準差變成 1

Z 表查表的四種對應

$$\begin{aligned} P(Z \le z) &= 0.5 + P(0 \le Z \le z) \\ P(Z > z) &= 0.5 - P(0 \le Z \le z) \\ P(-z \le Z \le z) &= 2 \cdot P(0 \le Z \le z) \\ P(-z_1 \le Z \le z_2) &= P(0 \le Z \le z_1) + P(0 \le Z \le z_2) \end{aligned}$$
符號解釋
Z 表內值
多數教科書列出 $P(0 \le Z \le z)$（半邊面積），須加減 0.5 轉成左尾/右尾
跨 0 的區間
拆成左半邊 + 右半邊，左邊用對稱換成正 z 查

常態近似二項分配

$$B(n, p) \xrightarrow{np \ge 5,\ n(1-p) \ge 5} N\!\left(np,\ np(1-p)\right)$$
$$Z = \frac{X - np}{\sqrt{np(1-p)}} \approx N(0, 1)$$
符號解釋
$np$
二項分配的期望值（取代常態 $\mu$）
$np(1-p)$
二項分配的變異數（取代常態 $\sigma^2$）
條件 $np, n(1-p) \ge 5$
確保 $n$ 大且 $p$ 不極端，常態近似才可靠
與波松近似的差別
波松近似條件是 $n \ge 20$ 且 $np \le 7$（罕見事件）；常態近似則需 $p$ 不太極端

$$P(\mu - k\sigma \le X \le \mu + k\sigma) \approx \begin{cases} 0.6827, & k=1 \\ 0.9545, & k=2 \\ 0.9973, & k=3 \end{cases}$$
符號解釋

常用更精確值

樣本平均數的分配

$$E(\bar X) = \mu,\quad \mathrm{Var}(\bar X) = \frac{\sigma^2}{n},\quad \sigma_{\bar X} = \frac{\sigma}{\sqrt{n}}$$
符號解釋
$\bar X$
樣本平均數（隨機變數）
$n$
樣本數
$\sigma_{\bar X}$

中央極限定理 (CLT)

$$\bar X \;\overset{\text{大 } n}{\approx}\; N\!\left(\mu, \frac{\sigma^2}{n}\right)$$
符號解釋
大 $n$
實務上 $n \ge 30$ 即可
不論母體分配
CLT 不要求原母體常態，只要 $n$ 夠大就好
用途
讓常態查表變得「處處可用」於估計與檢定
假設檢定（五步驟與決策規則）

Z 統計量（大樣本平均數）

$$Z = \frac{\bar X - \mu_0}{s / \sqrt{n}}$$
符號解釋
$\bar X$
樣本平均數（用樣本算出）
$\mu_0$
虛無假設中的母體平均數（題目給定的值）
$s$
樣本標準差（σ 已知時改用 σ）
$s / \sqrt n$
標準誤 SE
適用
大樣本 $n \ge 30$，或 σ 已知

t 統計量（小樣本平均數）

$$t = \frac{\bar X - \mu_0}{s / \sqrt{n}},\quad \nu = n - 1$$
符號解釋
公式
跟 Z 一樣，但分配是 $t_\nu$ 不是 $N(0,1)$
$\nu = n - 1$
自由度，查 t 表用
適用
小樣本 $n < 30$ 且 σ 未知

拒絕域對照表（依檢定方向）

檢定方向$H_1$拒絕域（Z 檢定）
單尾右尾$\mu > \mu_0$$Z > Z_\alpha$（α=0.05 時 > 1.645）
單尾左尾$\mu < \mu_0$$Z < -Z_\alpha$（α=0.05 時 < −1.645）
雙尾$\mu \neq \mu_0$$|Z| > Z_{\alpha/2}$（α=0.05 時 |Z|>1.96）
記憶口訣
看 $H_1$ 不等號方向
大於 → 右尾、小於 → 左尾、不等於 → 雙尾
雙尾要除 2
α 平均分到兩側，所以查 $Z_{\alpha/2}$（α=0.05 → 1.96，不是 1.645）

p-value 決策規則

$$p\text{-value} = \begin{cases} P(Z > |z_\text{樣}|) & \text{單尾} \\ 2 \cdot P(Z > |z_\text{樣}|) & \text{雙尾} \end{cases}$$
$$p < \alpha \Rightarrow \text{拒絕 } H_0;\quad p \ge \alpha \Rightarrow \text{保留 } H_0$$
符號解釋
$z_\text{樣}$
由樣本算出的 Z 統計量
單尾 p
只看一邊的尾端機率
雙尾 p
單尾結果乘 2（因為兩邊都要算）
意義
「如果 $H_0$ 為真，看到目前樣本（或更極端）的機率」

兩種誤差對照

實際 / 決策不拒絕 $H_0$拒絕 $H_0$
$H_0$ 為真✅ 正確（機率 $1-\alpha$）❌ 型 I 誤差（機率 $\alpha$）「冤枉好人」
$H_0$ 為假❌ 型 II 誤差（機率 $\beta$）「放過壞人」✅ 檢定力（機率 $1-\beta$）
t 分配對應（小樣本推論）

t 統計量（單樣本平均數）

$$t = \frac{\bar X - \mu}{S / \sqrt{n}},\quad t \sim t_{\nu = n - 1}$$
符號解釋
$\bar X$
樣本平均數
$\mu$
母體平均數（虛無假設值）
$S$
樣本標準差（用來取代未知的 σ）
$S / \sqrt{n}$
樣本平均數的標準誤（用 S 估計）
$\nu = n - 1$
自由度，因為樣本平均數已用掉一個

t 分配與 Z 分配對比

使用情境用哪個統計量
母體 σ 已知Z 分配$Z = \dfrac{\bar X - \mu}{\sigma / \sqrt{n}}$
大樣本 $n \ge 30$、σ 未知Z 分配（用 S 近似）$Z \approx \dfrac{\bar X - \mu}{S / \sqrt{n}}$
小樣本 $n < 30$、σ 未知t 分配$t = \dfrac{\bar X - \mu}{S / \sqrt{n}}$
規律
$\nu$ 越大
t 分配越接近 Z 分配（尾巴變瘦）
$\nu \to \infty$
$t_\nu \to Z$，兩者完全相同
$\nu = 120$ 時
$t_{120,\ 0.025} = 1.9799 \approx Z_{0.025} = 1.96$
